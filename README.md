# Помощник инженера дата-платформы — эталонное решение

Сервис по контракту кейса «Предскажи сбои выгрузок данных»: импорт истории в PostgreSQL, признаки на
момент прогноза, baseline на правилах, модель риска (градиентный бустинг scikit-learn) и тревоги с
причинами и рекомендациями.

## Запуск

    docker compose up --build

Сервис — http://localhost:8000, база — PostgreSQL из compose. Без Docker: Python 3.12,
`pip install -r requirements.txt`, `DATABASE_URL=postgresql://… uvicorn app.main:app`.

## Обучение

    python train.py ../datasets/open

Обучение — 50 дней, валидация — 20. Пороги выбраны на валидации — полнота 0,80 по ошибкам,
опозданиям и общей тревоге с наименьшим числом тревог. На валидации: полнота тревоги 0,82, ошибок
0,82, опозданий 0,81, точность 0,60; пороги — 0,1229 и 0,0874. Модель — `model/model.joblib`.

## Как устроено

- `app/store.py` — проверка строк в порядке контракта, дубли, хранение в PostgreSQL;
- `app/engine.py` — признаки на момент прогноза: события применяются в порядке `observed_at` и только
  до `prediction_at` запуска; ответы о запуске считаются один раз и не переписываются;
- `app/rules.py` — baseline и слова тревоги: причины и что проверить;
- `train.py` — обучение тем же движком признаков, что и в сервисе.
